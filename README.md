## 📌 Project Overview

This project demonstrates the design and configuration of an enterprise network using Cisco Packet Tracer.

The network includes multiple VLANs, trunking, inter-VLAN routing, DHCP, static routing, a server network, and communication between two routers.

---

## 🎯 Objectives

- Understand VLANs
- Configure access ports
- Configure trunk links
- Implement Router-on-a-Stick
- Configure DHCP
- Configure router-to-router communication
- Configure static routing
- Configure a server VLAN
- Test end-to-end connectivity
- Practice network troubleshooting
